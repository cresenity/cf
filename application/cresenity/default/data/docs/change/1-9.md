## CML

- Add `CML::associationRules($transactions, $minSupport, $minConfidence, $maxItemsetSize)` — Apriori association rule mining over transaction baskets, returning `{antecedent[], consequent, support, confidence, lift}` sorted by lift. Answers "buy A and B, usually also C" (bundling/promo) rather than "what is similar to A"; lift is what separates a real association from an item that is merely popular, since a ubiquitous item scores perfect confidence but lift 1
- Add `CML::itemCollaborativeSimilarity($transactions, $topK, $maxItemPerTransaction)` — item-to-item collaborative filtering ("customers who bought this also bought that") over transaction baskets, using Rubix ML's `Kernels\Distance\Cosine` on each item's occurrence vector. Cosine rather than a raw co-occurrence count so a bestseller does not look related to everything merely by being in most baskets; small baskets are weighted `1/(n-1)`, and only pairs that actually co-occur are computed
- `CML::itemCollaborativeSimilarity()` gains an optional `$minPairSupport` (default `1`, unchanged behaviour) — cosine scores a pair seen in a single basket the same 1.0 as one proven hundreds of times, so a support floor is the only way to keep coincidences out of the top of the list
- Add `CML::textSimilarity($text, $candidates)` — cosine similarity between a text and a list of candidate texts via TF-IDF vectors (already-vendored Rubix ML: `WordCountVectorizer` + `TfIdfTransformer` + `Kernels\Distance\Cosine`), for word-overlap-based near-duplicate detection with no external embedding API or vector DB needed
