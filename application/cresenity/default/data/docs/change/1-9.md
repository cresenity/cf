# Change Log 1.9

## CF

- `CFConfig::bootstrap()` now caches the merged configuration under `temp/cache/<appCode>/`, rebuilt automatically whenever a config file, a config directory or the app's `env.php` changes - no command to run, and no step to add to a deploy
- A config key whose value is built fresh on every load (a `uniqid()` cache-buster in `client_modules.php`, say) is detected and left out of that cache, so it keeps being evaluated per request as before
- `CFConfig::getCachedConfigPath()` accepts an optional variant name, appended to the cache file name
- `phpcf claude:install` now also installs a `PreToolUse` hook into `~/.claude/settings.json` that blocks hand-edits of `CLAUDE.md`/`docs/TODO.md`/`docs/BACKLOG.md` (devcloud-managed, never hand-edited) - re-run to pick it up on an existing install
- Fix `c::e()` (Blade's `{{ }}` echo handler) throwing a `TypeError` from `htmlspecialchars()` when the value is an array (e.g. a scanner sending `?field[]=x`) - it now renders as an empty string instead of crashing every view that echoes it
- Fix `CDatabase_Query_Concern_BuilderWhereTrait::invalidOperator()`/`isBitwiseOperator()` crashing `strtolower()` when a `where()` clause built from raw request input gets an array-typed operator - now treated as just another unrecognized operator
- Fix `CRouting_UrlGenerator::isValidUrl()` crashing `preg_match()` on an array-typed `$path` (reachable via `asset()`/`media()`) - now simply not a valid URL
- Fix `League\Flysystem\PathTraversalDetected` (e.g. a scanner probe on a temp-file path like `imgupload/../../../etc/passwd`) rendering as a 500 - it's Flysystem's own guard correctly refusing the traversal before touching any adapter, so it now maps to a 404 like other malformed-input exceptions, in both `CException_ExceptionHandler` and `CApi_ExceptionHandler`
- Fix `League\Flysystem\CorruptedPathDetected` (a path with control characters, e.g. a scanner payload) rendering as a 500 - maps to a 404 like `PathTraversalDetected`, in both handlers
- Fix file manager error handler crashing on a `null` error body - `typeof null` is `'object'`, so the guard passed and reading `.message` threw, hiding the real failure
- Fix `.htaccess` blocking `system/media`, so framework assets served from there (e.g. the CF1.6 file manager's `fm.js`) returned 403 - the exemption alongside `modules/*/media` was missing
- Fix filemanager building `//` into every URL and storage path when `root_path` ends with a slash - `rtrim()` was called without a character list, so it stripped whitespace instead of slashes
- Add `tests/Manager/FileManagerCategoryNameTest` (5 tests) covering the `root_path` + category join
- Fix vendored Dompdf `Renderer\Inline` throwing `Unsupported operand types: string + float` on PHP 8 when an inline child's padding-box height is a non-numeric CSS value — the inline renderer now compares heights as floats, matching the width handling on the lines above it
- Pin `phpcs` to 3.13.6 and `php-cs-fixer` to 3.95.18, both running on PHP 7.4 through 8.4 - the previous 3.13.0 fixer refused PHP 8.2 and above
- Fix `phpcs:install`/`php-cs-fixer:install` keeping an unsupported phar forever - they checked the file existed, never its version
- Add `--standard` and `--show-sources` to `phpcs`, and `--config` to `php-cs-fixer` and `php-cs-fixer:format`, so a caller outside the app directory can pick the ruleset
- Add `CQC::pharVersion()` and `CQC::downloadPhar()`, which verifies the download before replacing a working phar
- Add `tests/Server/WebServerSudoFallbackTest` (5 tests) guarding the `sudo -n` fallbacks in `CServer_WebServer::inspect()`
- Fix `CServer_WebServer_LiteSpeed::readFile()` reporting `missing` for a readable file when its parent directory is not traversable - `[ -e ]` guarded the `sudo` path, and `/usr/local/lsws/conf` is 0750
- Add `tests/Server/LiteSpeedReadFileSudoTest` (4 tests) guarding the check order in `readFile()`
- Add `tests/Pagination/UrlWindowTest` (15 tests) and `tests/Pagination/CursorTest` (12 tests) covering the page-window thresholds and the cursor encode/decode round trip
- Add `tests/Pagination/CursorPaginatorTest` (16 tests) and `tests/Pagination/PaginationStyleTest` (6 tests), completing the Pagination module at 70 tests
